# Technical Support Bot / Бот Технической Поддержки

## English / Английский

This bot serves as a tool for reaching out to the technical support department with inquiries and issues. It also automates the process of creating cards in Trello for more efficient request handling.

### How to Use

1. **Bot Setup:**
   - To run the bot, make sure you've installed the necessary libraries. You can use the command `pip install -r requirements.txt` to install all the required dependencies.

2. **Starting a Conversation with the Bot:**
   - Initiate a chat with the bot by sending the `/start` command.
   - The bot will send you a welcome message containing information on how to use it to contact the technical support department.

3. **Sending a Request to the Technical Support Department:**
   - To reach out to the technical support department, send your inquiry or issue in the following format:
     ```
     [department] [last name] [first name] [problem]
     ```
   - Example request:
     ```
     Technical Department, Ivanov Ivan, Computer Problem
     ```

4. **Limitations:**
   - Please refrain from sending stickers, voice messages, or other media files, as the bot does not support their processing.

5. **Instructions:**
   - You can receive usage instructions by sending the `ℹ️Instructions` command. The bot will provide information on the correct request format and advise against sending media files.

6. **Request Processing:**
   - After sending a request to the technical support department, the bot will forward your message to a staff member in the department.
   - The bot will also create a card in Trello with details of your request, including the department, last name, first name, and problem.

7. **Awaiting a Response:**
   - The bot will respond with a video message, indicating that your request will be processed within 15 minutes.

8. **Completing the Interaction:**
   - After finishing the conversation with the bot, you can close the chat.

This bot streamlines the process of contacting the technical support department and automates the creation of Trello cards for more efficient request handling.

## Русский / Russian

Этот бот служит инструментом для обращения в технический отдел с вопросами и проблемами. Он также автоматизирует создание карточек в Trello для более эффективной обработки запросов.

### Инструкция по использованию

1. **Настройка бота:**
   - Для запуска бота убедитесь, что вы установили необходимые библиотеки. Вы можете использовать команду `pip install -r requirements.txt` для установки всех необходимых зависимостей.

2. **Начало общения с ботом:**
   - Начните чат с ботом, отправив команду `/start`.
   - Бот отправит вам приветственное сообщение, содержащее информацию о том, как использовать его для обращения в технический отдел.

3. **Отправка запроса в технический отдел:**
   - Для обращения в технический отдел отправьте ваш запрос или проблему в следующем формате:
     ```
     [отдел] [фамилия] [имя] [проблема]
     ```
   - Пример запроса:
     ```
     Технический отдел, Иванов Иван, Проблема с компьютером
     ```

4. **Ограничения:**
   - Пожалуйста, не отправляйте стикеры, голосовые сообщения и другие медиафайлы, так как бот не поддерживает их обработку.

5. **Инструкция:**
   - Вы можете получить инструкцию по использованию бота, отправив команду `ℹ️Инструкция`. Бот предоставит информацию о правильном формате запроса и рекомендации по отношению к медиафайлам.

6. **Обработка запроса:**
   - После отправки запроса в технический отдел, бот пересылает ваше сообщение сотруднику этого отдела.
   - Бот также создает карточку в Trello с данными о вашем запросе, включая отдел, фамилию, имя и проблему.

7. **Ожидание ответа:**
   - Бот отвечает видеосообщением, указывая, что ваш запрос будет обработан в течение 15 минут.

8. **Завершение взаимодействия:**
   - По завершении беседы с ботом, вы можете закрыть чат.

Этот бот упрощает процесс обращения в технический отдел и автоматизирует создание карточек в Trello для более эффективной обработки запросов.
